# HDP Harness 本地诊断

HDP A1 是 DeepSeek Harness 的一个小型客户端插件。在会话页上方增加 **HDP 本地诊断** 面板，点击一次 **读取本次记录** 后，显示当前页面内存中最多三条诊断元数据。成功时按钮变为不可点击。

源码版本：`0.2.0-b7-minimal-fix-candidate`。这里保留交付版本号，发布 2026-10-03 交付中的原创运行代码，并补充 MIT 许可证、通用指南和离线测试。

## 功能与边界

记录包含客户端初始化、页面 hostname 判断、限定范围的读取完成事件；每条记录绑定本次运行标识和构建标识。服务端入口为空操作。页面内存中的记录随插件生命周期结束而清除。

本插件代码不读取聊天正文，不将诊断记录写入磁盘，不发起网络或模型请求。面板本身不需要 API Key。宿主软件的联网、聊天和数据处理行为另行管理。

`SCOPED_RECORD_SET_COMPLETE` 仅表示本次限定元数据读取完成，不证明模型、外部工具、远程功能或整个宿主的安全状态。来源判断接受 `localhost`、`127.0.0.1`、`::1`、`[::1]`；其他来源会产生拒绝记录，仍可在面板中查看。这是一项诊断判断，不是权限隔离或网络阻断机制。

## 可复现的源码检查

本次使用 Node `v24.13.0`。测试无外部依赖，无需先安装 npm 包：

```sh
git clone https://github.com/hx303/hdp-harness-local-diagnostics.git
cd hdp-harness-local-diagnostics
node --check lib/client.js
node --check lib/server.mjs
node tests/verify-offline.mjs
```

预期为 13 项测试通过；`npm test` 执行相同检查。这些测试使用 Node VM 及 React/Cordis 接口模拟，不会启动宿主，不能证明真实桌面安装成功。

## 安装与使用

请先阅读 [安装与使用指南](docs/INSTALL.md)。仓库提供源码，不包含 DeepSeek Harness 主程序、原电脑冻结安装工具、恢复包或用户配置。原包声明宿主约束 `0.1.7-rc.2`，其他版本兼容性尚未通过本次发布检查验证。

在已经正确集成插件的宿主中，进入会话页，展开 **HDP 本地诊断**，点击 **读取本次记录** 一次。成功后按钮禁用。失败时不要连续点击；同一面板只尝试读取一次，应检查宿主版本与接口兼容性。

原交付安装器依赖特定机器路径和冻结配置，并记录过配置不匹配；它不是可直接用于任意电脑的通用安装器。本仓库未保留或运行这些工具，也未修改用户配置。
